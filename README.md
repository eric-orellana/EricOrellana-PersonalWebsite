# EricOrellana-PersonalWebsite

Personal website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Edit content quickly

- Main site content is in `src/data/siteContent.js`
- Reusable UI components are in `src/components`
- App-level layout/styles are in `src/App.jsx` and `src/App.css`
